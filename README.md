### 🚀 Projetos em destaque

#### 🎯 Roleta do DEV

Aplicação Full Stack com 3.600 desafios de programação, desenvolvida com React, Node.js e PostgreSQL. Integra Front-end, API REST e banco de dados para filtrar e sortear exercícios.

**Tecnologias:** React, TypeScript, Tailwind CSS, Node.js, Express, Prisma ORM e PostgreSQL.

🔗 [Aplicação](https://roleta-do-dev.netlify.app/) | [Repositório](https://github.com/GuilhermePerobelliZambolim/roleta-do-dev)

#### 🌤️ ClimaView

Aplicação meteorológica desenvolvida com React e TypeScript, com pesquisa de cidades, integração com duas APIs da Open-Meteo e previsão para os próximos cinco dias.

**Tecnologias:** React, TypeScript, Tailwind CSS, Vite e Open-Meteo API.

🔗 [Aplicação](https://climaview-weather.netlify.app/) | [Repositório](https://github.com/GuilhermePerobelliZambolim/ClimaView)
